# CSharp

C# es un lenguaje tipado, orientado a objetos y muy usado con .NET para aplicaciones web, escritorio, APIs y sistemas empresariales.

## Conceptos clave

- Clases, objetos, interfaces y herencia.
- Tipos fuertes, genericos y colecciones.
- LINQ para consultar objetos y datos.
- `async` y `await` para operaciones asincronas.
- ASP.NET Core para APIs y aplicaciones web.

## Buenas practicas

- Definir responsabilidades claras por clase.
- Usar inyeccion de dependencias en servicios.
- Validar entradas antes de procesar datos.
- Manejar errores con excepciones y logs utiles.
- Separar modelos, servicios, controladores y acceso a datos.

## Uso recomendado

Usar C# cuando el proyecto necesita integracion con ecosistema Microsoft, APIs robustas, aplicaciones empresariales o servicios con .NET.

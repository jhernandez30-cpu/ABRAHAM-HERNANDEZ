# HTML y CSS

HTML define la estructura del contenido y CSS define la presentacion visual.

## HTML esencial

- Usar etiquetas semanticas: `header`, `main`, `section`, `article`, `nav`, `footer`.
- Mantener una jerarquia clara de encabezados.
- Agregar `alt` en imagenes importantes.
- Usar formularios con `label` asociado a cada campo.

## CSS esencial

- Usar variables para colores, espacios y tipografia.
- Crear layouts responsive con flexbox y grid.
- Evitar solapamientos en mobile y desktop.
- Priorizar legibilidad, contraste y consistencia.

## Buenas practicas

- Separar estructura, estilos y comportamiento.
- Probar en pantallas pequenas antes de cerrar cambios.
- Mantener botones y enlaces distinguibles.
- Reducir estilos duplicados cuando aparece un patron repetido.

# JavaScript

JavaScript permite crear interactividad en el navegador y tambien construir backend con Node.js.

## Conceptos clave

- Variables con `const` y `let`.
- Funciones, callbacks, promesas y `async/await`.
- Manipulacion del DOM en frontend.
- Eventos, formularios y llamadas `fetch`.
- Modulos ES para separar archivos.

## Buenas practicas

- Evitar variables globales innecesarias.
- Validar datos recibidos desde formularios o APIs.
- Manejar errores de red y estados de carga.
- Separar logica de interfaz, datos y utilidades.
- Usar nombres descriptivos para funciones y estados.

## Uso dentro de proyectos

JavaScript aparece en el portafolio, el asistente de programacion web, chatbots, animaciones y sitios estaticos conectados al puente local.

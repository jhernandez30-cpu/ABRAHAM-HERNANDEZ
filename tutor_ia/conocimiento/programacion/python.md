# Python

Python es un lenguaje de alto nivel usado para automatizacion, backend, analisis de datos, IA y scripting.

## Conceptos clave

- Variables, tipos de datos y estructuras como listas, tuplas, diccionarios y conjuntos.
- Control de flujo con `if`, `for`, `while`, `break` y `continue`.
- Funciones, modulos y paquetes para organizar codigo.
- Manejo de archivos con `open`, `pathlib` y formatos como JSON o CSV.
- Manejo de errores con `try`, `except`, `finally` y excepciones propias.

## Buenas practicas

- Usar nombres claros y funciones pequenas.
- Separar logica, datos y presentacion.
- Crear entornos virtuales por proyecto.
- Guardar dependencias en `requirements.txt`.
- Probar el codigo con casos simples antes de integrarlo.

## Uso dentro de TUTOR_IA

Python es el lenguaje principal del backend de TUTOR_IA, Streamlit, procesamiento de archivos, ChromaDB y puentes locales.

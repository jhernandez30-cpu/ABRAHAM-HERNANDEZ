# Ataques comunes

## Phishing

Engaño por correo, mensaje o sitio falso para robar credenciales o inducir una accion.

## Fuerza bruta

Intentos repetidos de adivinar contraseñas. Se mitiga con MFA, rate limiting, bloqueo temporal y contraseñas robustas.

## SQL injection

Insercion de SQL malicioso en entradas no validadas. Se mitiga con consultas parametrizadas.

## XSS

Ejecucion de JavaScript malicioso en el navegador de otro usuario. Se mitiga escapando salida y validando entradas.

## Malware

Software malicioso que roba, cifra o altera informacion. Se reduce con actualizaciones, backups y control de permisos.
